# Система управления промышленными компаниями (Management System)

Это веб-приложение для управления промышленными компаниями (угольными и нефтяными) и их объединениями в холдинги. Проект демонстрирует применение объектно-ориентированного программирования (ООП), паттерна MVC (Model-View-Controller) и работу с базой данных через Hibernate.

##  Возможности

*   **Управление компаниями:** Создание, просмотр и удаление угольных и нефтяных компаний.
*   **Специфичные операции:**
    *   Для угольных компаний: добавление шахт, остановка расширения.
    *   Для нефтяных компаний: добавление скважин, проверка ресурсов.
*   **Расчеты:** Выполнение расчетов производства для выбранной компании.
*   **Управление холдингами:** Создание холдингов, поиск, добавление/удаление компаний из холдинга, удаление холдинга.
*   **Интерактивный интерфейс:** Современный и отзывчивый фронтенд с боковой навигацией, дашбордом, модальными окнами и уведомлениями.
*   **Темная тема:** Поддержка светлой и темной темы оформления.

## 🛠️ Технологии

### Backend
*   **Java**
*   **Spring Framework** (предположительно, судя по структуре пакетов `controllers`, `services`, `repository`)
*   **Hibernate / JPA** для работы с базой данных
*   **Maven** (для сборки проекта)

### Frontend
*   **HTML5**
*   **CSS3** (с использованием CSS-переменных для темизации)
*   **Vanilla JavaScript** (без использования фреймворков)

### База данных
*   Настройка осуществляется через файл `hibernate.cfg.xml`. Вероятно, используется **MySQL** или **PostgreSQL**.
